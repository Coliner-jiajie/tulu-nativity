# 诞临·图鲁 诞临阶段：形式化模型 v0.2（已按实测更正：法则无返还、垣星为生存向）

> 范围：只建模诞临阶段（铭文已攒满）的「星象 + 铭文法则」出牌决策。
> 目标：把规则写成一个可执行的随机决策过程（MDP），之后用搜索 / 强化学习求最优策略，并与基线策略对比。
> 本文所有数值来自官方预览图；图中含义不清的地方一律写成**带编号的假设（A-xx）**，实现时做成可切换的配置项，用来做敏感性分析。

---

## 0. 归一化与目标函数

**归一化。** 令诞临图鲁的攻击力 ATK = 1，所有固定伤害以「×ATK」为单位记录（960% 记作 9.6）。
所有与策略无关的乘区（记忆铭文 2.5%/层、命轮、造物攻击加成等）合并成常数 `M`，它对所有策略等比放大，不影响最优策略的选择，因此**优化时不计入**，需要真实伤害时再整体乘上去。

**目标函数。** 诞临阶段共 `N = 6` 个完整回合（理想状况：生命足够，不会提前归零）。

```
J(π) = E_π [ Σ_{t=1..N} R_t ]
```

`R_t` 是第 t 回合所有伤害事件的倍率之和（星象卡效 + 星潮奔涌）。

**以下内容与策略无关，不计入 J：**
- 「忘却前夜」的 8000%（80.0）固定伤害；
- 退场后每回合的随机星潮奔涌；
- 防御相关的存活问题（理想状况下不考虑）。

**同时报告：** 均值、标准差、5%/50%/95% 分位数。「最优」默认指期望最大；若需要稳健性，后续可改为风险敏感目标。

## 1. 对象与符号

| 符号 | 含义 |
|---|---|
| 种类 k ∈ {Z, H, Y} | 灾星 / 垣星 / 蕴星 |
| 星阶 r ∈ {1..5} | 星象的星阶 |
| 星象 c = (k, r) | 一张星象牌 |
| 牌库 D0 | 45 张：15 种 (k, r) 各 3 张（3 套） |
| 法则 L | 7 种：易象 YX、增辉 ZH、敛芒 LM、昭示 ZS、引辰 YC、拓途 TT、重衍 CY |
| I | 当前记忆铭文层数，初值 I0 = 50 |
| 星轨 | 长度 3 的序列，第 j 个位置的卡效触发 j 次 |

## 2. 状态空间

回合内状态：

```
s = ( t,                      # 当前回合 1..6
      Draw,                   # 抽牌堆：每种 (k,r) 剩余张数 n_draw[k,r] ∈ {0..3}
      Disc,                   # 弃牌堆：同上（用于可能的洗牌）
      HandS,                  # 手中星象（多重集，含本回合临时改动后的 (k,r)）
      HandL,                  # 手中法则（多重集，每张带当前费用 c ∈ {0, 5}）
      Track,                  # 已放入星轨的 0~3 张星象 (k,r) 序列
      I,                      # 记忆铭文层数
      B )                  # 跨回合累积的触腕伤害量 B（见 §4）
```

**可交换性。** 牌库洗牌后抽牌顺序对决策者不可见，且任何时刻只有牌库内各种牌的**数量**影响未来分布。
因此把 Draw 记作 15 维计数向量，整个问题是一个**完全可观测的 MDP**（不需要 POMDP / 信念状态）。

## 3. 回合流程

**回合开始：**
1. 从 Draw 抽 4 张星象进 HandS（若 Draw 不足，见 A-08）；
2. 从 7 种法则中不放回随机抽 2 张进 HandL，费用 5（A-02）；
3. 清空 Track（B 跨回合保留，A-06）。

**回合中**（可重复，任意次序）：
- `PlayLaw(i)`：打出一张法则，需 `I ≥ cost_i`；
- `PlayStar(i)`：把手中第 i 张星象放入下一个星轨位置 j，立即结算 §4.1 的卡效 × j。

**回合结束**：星轨放满 3 张后自动发动「星潮奔涌」（§4.2）并结束回合；然后弃置手牌与星轨（A-03），进入下一回合。
回合内最后一个动作必然是第 3 张星象，所以**所有法则必须在第 3 张星象放下之前打完**。

## 4. 伤害结算

### 4.1 星象卡效（放在星轨第 j 位时触发 j 次）

| 种类 | 每次触发 |
|---|---|
| 灾星 Z | 伤害 `f_Z` = 9.6 |
| 垣星 H | 伤害 `f_H` = 7.2；另有生存向效果（以自身防御力 18% 降低敌方攻击力，不计入伤害） |
| 蕴星 Y | 伤害 `f_Y` = 4.8；B += 0.03·ρ·m |

- 垣星的「临时力量降低」是以自身防御力的百分比降低敌方**攻击力**，属于生存向效果（已更正：之前误解为降低敌方防御）。理想状况下不计入伤害。
- `ρ` = DEF / ATK（归一化后的防御力，诞临造物加成已含在内）。
- `h` = H / ATK，H 为队伍最大生命（A-14）。**触腕伤害值 B**（按 ATK 归一化）：初值 B = 0.05·h；每个回合自然增长 0.0125·h·m（A-13）；蕴星卡效与星潮再按表累加；`m` = 铭文对获得触腕伤害的放大 = 1.25（A-09）。B 跨回合累积（A-06）。
- 默认假设卡效数值**不随星阶变化**（A-04）。预览图中灾 I、垣 III、蕴 V 的数值分别为 960 / 720 / 480，我们暂视为各自的固定值。

### 4.2 星潮奔涌

设星轨中三张牌为 (k1,r1), (k2,r2), (k3,r3)，记 `n_k` 为其中种类 k 的数量：

```
hits  = 3 + a(r1,r2,r3) + b(k1,k2,k3)
a = 6  若 r1 = r2 = r3
    3  若 {r1,r2,r3} = {m, m+1, m+2}（任意次序，A-05）
    0  其他
b = 6  若 k1 = k2 = k3
    3  若 k1,k2,k3 两两不同
    0  其他

每次伤害 per_hit = 9.6 + 1.6 · n_Z  (+ 3 · B 若 n_Z = 3，A-10)
垣星：每张降低敌方攻击力（生存向，忽略）
蕴星：每张使 B += 0.01 · ρ · m
若 n_H = 3：获得护盾（忽略）
若 n_Y = 3：tide 总伤害 × 1.02
```

**回合总倍率：**

```
R_t = Σ_{j=1..3} j · f(card_j)  +  hits · per_hit · (1.02 若 n_Y = 3)
```

垣星的效果是降低敌方攻击力（生存向），不放大伤害，因此伤害公式里没有降防项（A-11 已确认）。

### 4.3 单回合理论最大值（用于校验与上界）

| 牌型 | 卡效 | 星潮 | 合计 |
|---|---|---|---|
| 灾灾灾 + 同星阶 | 57.6 | 15 × 14.4 = 216 | **273.6** |
| 灾灾灾 + 连号 | 57.6 | 12 × 14.4 = 172.8 | 230.4 |
| 灾灾灾（无规律） | 57.6 | 9 × 14.4 = 129.6 | 187.2 |
| 垣垣垣 + 同星阶 | 43.2 | 15 × 9.6 = 144 | 187.2 |
| 蕴蕴蕴 + 同星阶 | 28.8 | 15 × 9.6 × 1.02 ≈ 146.9 | ≈ 175.7 |

同星阶三连要求「某个 (k,r) 的 3 张全部同时拿到」，所以**每个 (k,r) 一整局最多凑出一次**。因此理想上界为：

`5 × 273.6（5 个灾星同星阶，各一回合）+ 1 × 187.2（第 6 回合改用垣星）≈ 1555`

该上界只适用于「法则只能在星轨放满前不能打」的旧版规则。A-32 允许重衍在星轨未满时白嫖卡效后重来，理论上界不再有简单闭式，已从自检中移除；单回合最大值的牌型表（§4.3）仍然有效。

## 5. 法则的转移规则

| 法则 | 作用 | 备注 |
|---|---|---|
| 易象 YX | 手中每张星象独立随机变成另两种之一（各 1/2），星阶不变；本回合有效 | 只影响打出时的类型（A-03）。临时改动在回合结束时作废 |
| 增辉 ZH | 手中所有星象星阶 +1，本回合有效 | 边界规则见 A-05b（默认夹到 [1,5]） |
| 敛芒 LM | 手中所有星象星阶 −1，本回合有效 | 同上 |
| 昭示 ZS | 从 7 种法则中发现 3 张（不放回），选 1 张入手，其消耗变为 0 | 选择是决策 |
| 引辰 YC | 抽 2 张星象 | 手牌上限见 A-08 |
| 拓途 TT | 随机获得 3 张不同的法则（从 7 种中不放回） | 入手，费用 5 |
| 重衍 CY | 清空星轨，弃置全部手牌，抽 4 张星象，随机获得 2 张不同法则 | 已放入星轨的牌的卡效已触发，不退回 |

**铭文花费。** 已确认：打出一张法则消耗 5 层 I，无返还（A-01）；I0 = 50 最多打 **10** 张法则。法则打出后**不进入牌库**。
重生时记忆铭文的倍率已快照进 `M`，所以花费 I 不会降低伤害乘区（A-01b）。

**性质（可检验）：**
- 增辉/敛芒对所有手牌同步平移，**不改变星阶之间的相对差**；它们只有在边界夹取时才会产生「压缩」，让 (4,5,5) 变成 (5,5,5) 之类。
- 易象不改变星阶，因此不影响 a，只改变种类相关项。

## 9. 当前已能预见的结构性结论（待仿真验证）

1. 灾灾灾的单回合收益显著高于其他牌型（见 §4.3），因此**法则的核心用途是提高凑灾灾灾（并带连号/同星阶）的概率**。
2. 同星阶三连每个 (k,r) 一局最多触发一次，所以灾星同星阶最多 5 次，上界约 1555。
3. 法则预算：50 层、每张 5 层、无返还，全局最多打 **10 张**法则（约每回合 1.7 张），而每回合免费生成 2 张，所以**预算是硬约束**。哪些回合花、花在哪种法则上，是核心决策；预算的影子价格由仿真求出。
4. 灾星一共 15 张，三张灾星/回合最多支撑 5 个回合，第 6 回合的牌型选择会由牌库耗尽情况决定。
6. **星轨未满时打法则（A-32）带来两类新打法**：
   - **白嫖 + 重衍**：重衍会丢弃全部手牌，手里的星象本来就浪费，所以打重衍前应先把最好的两张放进星轨槽 1、2（卡效 1× 和 2× 已结算，最多 9.6 + 19.2 = 28.8），再重衍重新抽 4 张。
   - **先锁定再随机化**：把好牌先放进星轨，再用易象/增辉/敛芒改动剩余手牌；已放入星轨的牌不受影响，且增辉/敛芒只调整剩下的牌，可用来凑连号或同星阶。
   - 余波使每张未用法则回合末 +1 层铭文，使得「不打」也有 20% 的返还，打法则的净成本相当于 5 + 1。
5. 垣星没有伤害加成，单看输出比灾星弱、比蕴星强。蕴星的触腕伤害加成 B 跨回合累积，且只能在**不是 3 灾星的回合**里积累，而灾星只够支撑 5 个三灾回合，所以**第 6 回合天然空出**，可以让给蕴星。这样问题变成一个时机选择：蕴星回合放在最前面（越早，受益的三灾回合越多）。
   粗估（A-10 的加法读法）：一个蕴蕴蕴回合累积 ΔB = (6×0.03 + 3×0.01)·ρ·m = 0.2625ρ；之后每个三灾回合最多 15 次伤害、每次多 3·ΔB，5 个回合合计约 +59ρ；放在第 1 回合的代价只是第 6 回合垣垣垣与蕴蕴蕴的差额约 11.5。粗略的切换点 ρ ≈ 0.2，即 **ρ 只要大于约 0.2，蕴星回合就值得**。
   自然增长（每回合 +0.0125·h·m）与策略无关，它在加法读法下**不影响蕴星的边际价值**，只抬高所有三灾回合的伤害，不改变策略；但在乘算读法 (1+3B) 下会放大蕴星的收益。需要仿真验证。
