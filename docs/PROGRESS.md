# 2026-11-20 更新：DQN 路线试验（结论：不如 PPO 与蒸馏）

实现：`tulu/rl/qexpert.py`（专家为每个候选动作记录剩余回报的 Q 向量）、`DuelingQNet`（`networks.py`）、`tulu/rl/qlearn.py`（离线 DQfD 风格训练 + 在线 Double DQN：n 步回报、ε-greedy、目标网络软更新、混入专家数据）、`scripts/h_qdist.py`、`tests/test_qlearn.py`。

| 实验（含 +80，2 万局贪心评估） | 平均总倍率 |
|---|---|
| 离线 Q 网络（Q 回归 + 优势 + 间隔损失），2 万局专家数据 | 1204.4 |
| 同上，加监督项（把 Q 当 logits 匹配专家动作） | 1237.0 |
| 在线 Double DQN 微调（600 步，ε 0.05→0.01，混入专家数据） | 1219~1231（比起点 1236 更差，未保存） |
| 对照：行为克隆 / PPO 微调 ft3 / 专家 | 1267 / 1295.8 / 约 1288~1297 |

结论与原因（推测）：各动作的价值差距只有几分，而单局噪声约 ±100，价值回归要把相对排序学得很准；未被专家评估的动作会被高估（外推误差）；在线 TD 更新使已有的排序变差。分类式（行为克隆）和策略梯度（PPO）更适合这个问题。踩过的坑：滚动前瞻给的是整局总倍率，必须减去该状态之前已累计的倍率才是可学的 Q 目标。
没有保存 DQN 模型，最佳模型仍是 `models/ppo_ft3_last_1296.pt`。
